# Settings menu images

These assets were exported with Ardot MCP from the
`Settings App UI - iPhone Style` container (`8:8`). The SVG files preserve the
design vectors; the PNG files are the 42 x 42 pixel sources embedded by
`src/assets/settings_icons.cpp`.

| `settings-bluetooth` | `90:43` (`Bluetooth Icon Tile`) |

| `settings-battery` | `90:64` (`Battery Icon Tile`) |
| `settings-general` | `90:76` (`General Icon Tile`) |
